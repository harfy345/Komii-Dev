# Explore a project

## Purpose
Build an evidence-based understanding of an unfamiliar repository without exhaustively reading it.

## When to use
Use during initial Komii Dev setup or when a task enters an unfamiliar subsystem.

## Required initial context
Read `komii-dev/AGENT.md`, then inspect root manifests and relevant repository instructions.

## Workflow
1. Identify languages, frameworks, package managers, build tools, and test runners from manifests and configuration.
2. Map important directories, entry points, and tests.
3. Read representative files and trace dependencies relevant to the task.
4. Inspect CI, API, database, or migration definitions when relevant.
5. Separate verified facts from assumptions and record uncertainty.
6. Populate or update only affected knowledge files.

## Validation
Check every recorded path and command against the repository. Do not execute project scripts without user authorization.

## Knowledge updates
Keep summaries concise and source-grounded; do not invent historical rationale.
